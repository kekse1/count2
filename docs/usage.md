## CLI mode
If you want to run one of the PHP scripts in CLI mode (using a terminal),
you can start them via the `main.sh` script (which really needs to reside in
the `php/` directory); therefore use the **symbolic links** in the `sh/` directory.

Command line arguments are passed through to the scripts.
